# Брендбук ФАЙЗ на три заведения — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** вход с выбором заведения, брендбук вейп-шопа на своей странице, брендбук и страница инвесторов пекарни.

**Architecture:** статический сайт на GitHub Pages, все страницы в корне. Общие стили `brand.css`, тема пекарни `brand-bakery.css` поверх них. Калькулятор в `kit.js` настраивается разметкой страницы. Строка подразделов выносится в `subnav.js`, её используют обе страницы брендбука.

**Tech Stack:** HTML, CSS, ванильный JS, GSAP + Lenis (уже подключены), Google Fonts.

**Spec:** `docs/superpowers/specs/2026-11-22-multi-brand-brandbook-design.md`

## Global Constraints

- Палитра пекарни: голубой `#A0BEDA`, сливочный `#F4DEAF`, шоколад `#34211B`; логотип пекарни — шоколад.
- Шрифты пекарни: Playfair Display (заголовки), Manrope (текст).
- В материалах пекарни нет 18+, логотипа и паттерна вейп-шопа; в вейп-шопе нет логотипа еды.
- CSP страниц: скрипты только self, cdnjs, jsdelivr; шрифты — Google Fonts.
- Цифры калькуляторов — условный пример с пометкой.
- После изменения `*.css`/`*.js` поднимать `?v=` во всех страницах, которые их подключают.

## Review Focus

- Старые закладки `index.html#logo`, `#identity`, `#carriers`, `#templates`, `#store`, `#quick` → открывается `vape.html` с тем же якорем.
- Старая ссылка `invest.html` (и с якорем `#calc-s`) → `invest-vape.html` с тем же якорем.
- Калькулятор пекарни: 0 чеков или фудкост 100 % → «не окупается», без NaN/Infinity на экране.
- Вход на телефоне 375 px: три полосы помещаются без горизонтальной прокрутки, текст не обрезан.
- Брендбук пекарни: контраст текста на сливочном и голубом фоне не ниже 4,5 : 1 для основного текста.
