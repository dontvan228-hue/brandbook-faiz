# ФАЙЗ — файлы для печати и вышивки одежды

Все файлы векторные, в натуральную величину (миллиметры), текст переведён в кривые — шрифты устанавливать не нужно.
Каждый элемент есть в трёх цветах: `cream` (#F3EBD6), `olive` (#1A422F), `champagne` (#C8B48C). Форматы: SVG и PDF.

## Перед запуском тиража

- Цвета в файлах указаны в HEX. Попросите производство подобрать ближайший цвет нитей или краски и показать образец (выкрас) до запуска.
- Для вышивки производство само делает программу вышивки (дижитайзинг) по этим файлам — проверьте пробную вышивку на ткани.
- Не масштабируйте файлы непропорционально и не меняйте цвета вне этой таблицы.
