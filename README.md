# Брендбуки ФАЙЗ

Сайт с брендбуками заведений ФАЙЗ и страницами для инвесторов. На входе человек выбирает заведение и дальше видит только его брендбук.

| Заведение | Брендбук | Инвесторам | Статус |
|---|---|---|---|
| Вейп-шоп | `vape.html` | `invest-vape.html` | готово |
| Пекарня | `bakery.html` | `invest-bakery.html` | готово, фото позже |
| Шаурмичная | — | — | в разработке (полоса на входе) |

**Вейп-шоп:** шпаргалка, логотип (построение, минимальный размер, файлы), айдентика (цвета, контраст, типографика, паттерн, печать, фотостиль, иконки), носители (фото одежды, техкарты футболки, худи и поло, мерч, полиграфия, стикеры, соцсети), шаблоны, экскурсия по магазину.

**Пекарня:** шпаргалка, логотип (файлы, охранное поле, размеры, варианты, ошибки), айдентика (сливочный, голубой, шоколад; контраст; Playfair Display и Manrope; фотостиль), носители (упаковка, форма, вывеска, меню, ценник, соцсети), шаблоны.

## Контакты и показатели для инвесторов

Откройте `contacts.js` и заполните:

```js
window.FAIZ = {
  contacts: { email: 'invest@example.ru', telegram: 'faiz_invest', phone: '+7 900 000-00-00' },
  kpi: [{ v: '1', l: 'Магазин в сети' }, { v: '12 мес', l: 'Окупаемость точки' }]
};
```

Контакты общие для страниц инвесторов всех заведений. Пока поля пустые, кнопки связи и блок «Ключевые показатели» скрыты. Указывайте только реальные, подтверждаемые цифры.

## Состав

- `index.html` + `entry.css` + `entry.js` — вход: три полосы; `entry.js` переводит старые ссылки `index.html#раздел` на `vape.html#раздел`
- `invest.html` — переадресация со старого адреса на `invest-vape.html`
- `brand.css` — общие стили; `brand-bakery.css` — светлая тема пекарни поверх них
- `subnav.js` — строка подразделов под меню (общая для всех брендбуков)
- `app.js` — логика и анимации брендбука вейп-шопа; `invest.js` — страница инвесторов вейп-шопа
- `food.js` — логика брендбука и страницы инвесторов пекарни, нарисованные макеты носителей
- `kit.js` — иконки, техкарты, шаблоны, контакты и калькулятор окупаемости (два режима: выручка за месяц или чеки в день × средний чек × дни с фудкостом)
- `contacts.js` — контакты и показатели для инвесторов
- `logo/food/` — логотип пекарни и шаурмичной (SVG, PDF, PNG)
- `print/` — файлы для печати одежды вейп-шопа и ТЗ для производства
- `img/` — фотографии вейп-шопа и мерча
- `tests/check_site.py` — проверка ссылок, якорей, переадресаций и версий файлов: `python -P tests/check_site.py`
- `.claude/skills/faiz-brand-check/` — навык проверки материалов по брендбуку нужного заведения

## Как открыть

Сайт публикуется через GitHub Pages. Для локального просмотра скачайте весь репозиторий и запустите в его папке простой сервер, например `python -m http.server`, затем откройте `http://localhost:8000`. Нужен интернет для шрифтов и библиотек анимации.

После изменения `*.css` или `*.js` поднимите номер `?v=` в ссылках на этот файл во всех страницах — иначе браузеры покажут старую версию из кэша.

## Безопасность

- Внешние библиотеки (GSAP, Lenis) подключены с проверкой целостности (`integrity`). При обновлении версии библиотеки пересчитайте хеш, иначе браузер её не загрузит.
- Политика `Content-Security-Policy` в `<head>` разрешает скрипты только с этого сайта, cdnjs и jsDelivr. Новые внешние ресурсы нужно добавить в неё.
