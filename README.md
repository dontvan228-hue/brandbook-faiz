# Брендбук ФАЙЗ

Анимированный сайт-брендбук бренда «ФАЙЗ» и витрина для партнёров.

Разделы: «Брендбук за 30 секунд» (шпаргалка), платформа бренда (позиционирование, ценности, характер, аудитория, тон, правила 18+), логотип (построение, минимальный размер, SVG-файлы для скачивания), айдентика (цвета, пропорции, контраст, типографика и иерархия, паттерн, печать, фотостиль), иконки, носители (техкарты футболки и худи с размерами нанесения, мерч, полиграфия, стикеры, цифровые каналы), библиотека из 18 шаблонов и инструкция «макет за 4 шага», экскурсия по магазину и раздел «Партнёрам и инвесторам» с калькулятором окупаемости.

## Контакты и показатели для инвесторов

В `index.html` найдите блок `<script type="application/json" id="cfg">` и заполните:

```json
{"contacts":{"email":"invest@example.ru","telegram":"faiz_invest","phone":"+7 900 000-00-00"},
 "kpi":[{"v":"1","l":"Магазин в сети"},{"v":"12 мес","l":"Окупаемость точки"}]}
```

Пока поля пустые, кнопки связи и блок «Ключевые показатели» скрыты. Указывайте только реальные, подтверждаемые цифры.

## Состав

- `index.html` — разметка и стили
- `kit.js` — иконки, техкарты одежды, шаблоны и калькулятор (подключается перед `app.js`)
- `app.js` — основная логика и анимации (вынесена из HTML, чтобы работала политика безопасности CSP)
- `img/` — фотографии экскурсии и мерча

## Как открыть

Сайт публикуется через GitHub Pages. Для локального просмотра скачайте весь репозиторий (не только `index.html`) и запустите в его папке простой сервер, например `python -m http.server`, затем откройте `http://localhost:8000`. Нужен интернет для шрифтов и библиотек анимации.

## Безопасность

- Внешние библиотеки (GSAP, Lenis, three.js) подключены с проверкой целостности (`integrity`). При обновлении версии библиотеки пересчитайте хеш, иначе браузер её не загрузит.
- Политика `Content-Security-Policy` в `<head>` разрешает скрипты только с этого сайта, cdnjs и jsDelivr. Новые внешние ресурсы нужно добавить в неё.
